규칙 요약

SPX ±2.5% (V2)
  • 기준: S&P 500 지수(SPX) 종가와 200일선, 밴드 ±2.5%
  • 매수: SPX가 상단(+2.5%) 돌파 → SGOV로 TQQQ 3분할 매수 (분할 중 밴드로 내려와도 계속 매수)
  • 관망: 밴드 안에서는 기존 포지션 유지
  • 소익절 +10/25/50% → 잔고 10% · 대익절 +100/200/400/800%… → 잔고 50%, 덜어낸 금액은 SPYM
  • 연쇄 TS: 사이클 TQQQ 고점 대비 −25% → TQQQ 수량 50% SPYM 전환, 고점 리셋 후 반복
  • 전량 탈출: SPX가 하단(−2.5%) 이탈 → TQQQ·SPYM 전량 매도, SGOV 대피

사이클 수익률은 "매수 신호일 TQQQ 종가" 기준입니다. 실제 3분할 매수 평단과 다를 수 있습니다. 신호가 새로 나오면 GitHub 앱으로 알림이 갑니다. 규칙을 자동 계산한 참고 화면이며 투자 자문이 아닙니다.
